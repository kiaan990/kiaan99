How this thing thinks

What are weights?

A neuron receives numbers and has to decide how much each one matters. A weight is exactly that opinion: one number per incoming connection.

Biologically, a weight is a synapse. A strong positive weight is an excitatory synapse — "when this input fires, I fire harder." A negative weight is inhibitory — "when this input fires, shut up."

The neuron sums everything it hears, weighted: z = w₁x₁ + w₂x₂ + b. The extra bias b is the neuron's excitability — how eager it is to fire before any input arrives at all. It shifts the threshold.

Learning is nothing but nudging these numbers. The network's entire "knowledge" is the list of weights you see drawn as lines in the diagram.

What does an activation function do?

After the weighted sum z, the neuron passes it through an activation function — the firing rule.

Why it must be non-linear: stack two linear layers and you get… another linear layer. A straight line. Without a squash step, a 50-layer network could still only draw one straight boundary. The activation is what lets the boundary bend. Try XOR — no straight line separates it, so the curvature is essential.

ReLU max(0, z) — fires proportionally when excited, silent when not. Closest to a real neuron's "threshold then rate". Fast, but a neuron stuck below zero gets zero gradient and can die.

Sigmoid squashes to (0, 1) — a soft "probability of firing". Gradients go nearly flat at the extremes, so learning crawls.

Tanh squashes to (−1, 1) — like sigmoid but centred on zero, so neurons can vote both for and against. Usually the best default here.

The output neuron always uses sigmoid in this playground, because we want a probability between 0 and 1.

What is backpropagation?

Three steps, repeated forever:

1. Forward pass. Push a point (x, y) through the layers and get a prediction p. That's the network "thinking".

2. Measure the error. Compare p to the true label with a loss function. Here: binary cross-entropy, which punishes confident wrong answers brutally and shrugs at confident right ones.

3. Backward pass. Assign blame. Work backwards through the network asking, for every single weight: "if I had nudged you up a hair, would the error have gone down?" That answer is the gradient. The chain rule from calculus is what lets blame flow back through layer after layer.

Then updateWeights steps every weight a little way against its gradient — downhill on the error surface. That step size is the learning rate. Too small and you crawl; too big and you bounce over the valley and the loss explodes. Crank it to 0.5 on the spiral to see the chaos.

There's no biological equivalent of backprop, honestly — real brains don't ship error signals backwards down the same wires. It's an engineering trick that happens to work extraordinarily well.

Why does the picture look like that?

Each hidden neuron carves the plane with one straight cut (its weights set the cut's angle, its bias sets the offset). The activation function softens that cut into a ramp.

The output neuron then takes a weighted vote among those cuts. Combine 4 soft cuts with the right votes and you can box in a quadrant, ring a circle, or trace a spiral. That's the whole trick — and it's why one hidden neuron can only ever give you a single straight boundary.

Watch the diagram while you hover the map: the lit-up hidden neurons are the ones "responsible" for the region your mouse is in.

Things worth trying

• XOR with 1 hidden neuron. Loss stalls near 0.55 and accuracy plateaus around 65–70%, then never improves. One hidden neuron can only draw one straight line, and the best a straight line can do is shave a corner off a single quadrant. A hard capacity limit you can see.

• Reset weights repeatedly on the spiral. Same architecture, same data, wildly different outcomes — random initialisation decides which valley you roll into.

• ReLU with learning rate 0.5. Watch neurons die (their lines go limp and never recover).

• Sigmoid on the spiral. Painfully slow — you're feeling the vanishing gradient problem that stalled neural networks for a decade.
