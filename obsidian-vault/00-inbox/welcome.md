# Welcome to your second brain

This vault is your persistent, searchable, cross-referenced memory for
coding work. It lives at `/home/user/Obsidian/SecondBrain` and is wired
into Claude Code.

## Read these first

- [[CLAUDE]] — operating contract every Claude session follows in this vault
- [[README]] — human-readable map of the vault and day-to-day commands

## Five things to remember

1. Say **"start a new project for X"** to spin up a project note.
2. Say **"have I solved this before?"** before any non-trivial new work.
3. Say **"wrap up project Y"** when something ships, pauses, or dies — this
   writes the retro and extracts patterns automatically.
4. Say **"rollup my day"** at end-of-day to sync today's daily note.
5. Drop `90-meta/templates/project-CLAUDE.md` into any new repo to bridge
   it back to this vault.

## Self-learning

This vault makes its own connections. Every new note gets auto-linked into
the graph; recurring lessons across retros become patterns automatically;
stale projects and orphan notes surface in the daily rollup. See the
"Self-learning loop" section of [[CLAUDE]] for the full contract.
