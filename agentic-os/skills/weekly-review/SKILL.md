# Weekly review

Look back on the week and set up the next one.

## Workflow

1. Read the files changed this week (the list is given in the task): raw inputs, wiki notes and outputs.
2. Group what happened into themes: wins, things learned, things left unfinished.
3. Spot raw notes that are now durable knowledge and should be promoted from `raw/` to `wiki/`. **List them only**: do not move, rename or edit anything.
4. Suggest 3 focus areas for next week.
5. Write the review with `template.md` as a NEW file in `outputs/reviews/` (exact path given in the task).

## Rules

- Link to the notes you mention with `[[wikilinks]]`.
- Be honest and specific; skip filler praise.
