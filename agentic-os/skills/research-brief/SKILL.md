# Research brief

Turn a topic into a short, sourced brief the user can read in five minutes.

## Workflow

1. Check the vault first: search `wiki/` for notes on the topic and reuse what is already known.
2. Search the web. Prefer primary sources, official docs, peer-reviewed work and reputable outlets. Note the publication date of each source.
3. Read the 4–8 most useful sources. Skip anything paywalled or low quality.
4. Write the brief using `template.md` in this folder.
5. Save it as a NEW file at `outputs/research/YYYY-MM-DD-topic-in-kebab-case.md` (the exact path is given in the task). Never edit or overwrite existing files.

## Rules

- Every factual claim gets a citation like [1] that matches the Sources list.
- Say plainly when sources disagree or evidence is thin.
- Keep the Summary to 5 bullets. Whole brief: under ~800 words.
- No invented sources, quotes or numbers.
